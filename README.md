# plugregex

Plug URLs and regex query parts with stable normalization.

**Site:** https://theworker02.github.io/plugregex/

## Install / run

```bash
git clone https://github.com/theworker02/plugregex.git
cd plugregex
node src/cli.js
node --test
```
